# 数学建模竞赛工作流指南

## 工作流概述

本工作流采用**人机协作模式**，以用户为主导，AI提供辅助支持。

### 核心原则

1. **用户主导**：关键决策和图片生成由用户完成
2. **AI辅助**：AI负责数据处理、参数建议、结果解读
3. **权威可信**：图表通过权威在线工具生成，保证可信度

---

## 工作流阶段

| 阶段 | 责任主体 | 主要任务 | 输出物 |
|------|----------|----------|--------|
| 1. 题目解析 | AI辅助 | 解析题目，提取关键信息 | 题目分析报告 |
| 2. 模型选型 | AI辅助 | 选择合适的数学模型 | 模型选择报告 |
| 3. 数据处理 | AI辅助 | 数据清洗、特征工程 | 处理后的数据集 |
| 4. 模型求解 | AI辅助 | 训练模型、计算指标 | 求解结果 |
| 5. **结果可视化** | **用户主导** | 操作在线工具生成图表 | 高质量图表 |
| 6. 模型验证 | AI辅助 | 验证模型有效性 | 验证报告 |
| 7. 论文撰写 | 人机协作 | AI生成草稿，用户修改 | 论文初稿 |

---

## 阶段5：结果可视化（用户主导）

### AI职责

1. **准备数据**
   - 将求解结果转换为CSV格式
   - 整理特征重要性、灵敏度分析等数据
   - 保存到 `figures/data_*.csv`

2. **生成参数建议**
   - 推荐图表类型
   - 提供标题、标签、颜色等参数
   - 保存到 `figures/visualization_guide.json`

3. **提供操作指引**
   - 推荐权威在线工具
   - 详细操作步骤
   - 结果解读方法

4. **解读结果**
   - 分析图表含义
   - 提供结论建议

### 用户职责

1. **操作在线工具**
   - 打开推荐的在线可视化工具
   - 上传AI准备的数据文件
   - 按照参数建议设置图表

2. **生成图表**
   - 调整图表样式
   - 导出高质量图片
   - 保存到 `figures/` 目录

3. **质量控制**
   - 检查图表准确性
   - 确保数据一致性
   - 验证可视化效果

## 推荐在线可视化工具

### 1. Plotly

- **网址**: https://plotly.com/python/
- **特点**: 交互式图表，支持在线编辑和导出
- **适用**: 散点图、折线图、热力图、3D图表
- **优势**: 专业、美观、支持多种导出格式

### 2. Tableau Public

- **网址**: https://public.tableau.com/
- **特点**: 专业数据可视化平台，免费版可用
- **适用**: 仪表板、交互式图表、地理图表
- **优势**: 功能强大，适合复杂可视化

### 3. Google Charts

- **网址**: https://developers.google.com/chart
- **特点**: 简单易用的在线图表工具
- **适用**: 柱状图、饼图、折线图
- **优势**: 易上手，适合快速生成

### 4. RAWGraphs

- **网址**: https://rawgraphs.io/
- **特点**: 开源数据可视化工具，支持多种图表类型
- **适用**: 复杂图表、自定义可视化
- **优势**: 开源免费，图表类型丰富

### 5. Datawrapper

- **网址**: https://www.datawrapper.de/
- **特点**: 专业新闻图表工具，适合论文图表
- **适用**: 柱状图、折线图、地图
- **优势**: 简洁专业，适合学术论文

## 质量保证

### 图表质量要求

1. **数据准确**: 图表数据与计算结果一致
2. **标注完整**: 包含标题、坐标轴标签、图例
3. **格式规范**: 符合学术论文图表规范
4. **可溯源**: 标注数据来源和生成工具

### 可信度保证

1. **权威工具**: 使用公认的专业可视化平台
2. **真实数据**: 基于实际计算结果
3. **完整过程**: 保留数据文件和操作记录
4. **可复现**: 提供完整参数和配置

## 使用示例

### 步骤1: 运行工作流

```bash
cd 工作流
python main.py --all
```

### 步骤2: 查看可视化指引

```bash
cat 项目目录/figures/visualization_guide.json
```

### 步骤3: 打开在线工具

访问推荐的在线可视化工具（如Plotly）

### 步骤4: 上传数据

将 `figures/data_*.csv` 文件上传到在线工具

### 步骤5: 生成图表

按照参数建议设置图表样式

### 步骤6: 导出图片

将生成的图表导出为PNG/SVG格式

### 步骤7: 保存图片

将导出的图片保存到 `figures/` 目录

## 注意事项

1. **缓存管理**: 修改代码后使用 `--no-cache` 参数重新运行
2. **数据验证**: 生成图表前检查数据文件内容
3. **工具选择**: 根据图表类型选择合适的在线工具
4. **质量检查**: 导出图片后检查清晰度和准确性
